# Your Agent in One Emoji

One emoji that stands for an AI agent: 🧭

A compass. An agent takes a goal and finds the way through it on your behalf — it navigates, decides the next turn, and keeps you on course while you look elsewhere. Not a robot face, not a smiley: a tool for finding direction, which is what the agent actually does.

## How it works

`main.py` writes the single emoji to `/output/entry.txt` when run.
